  baked index; 1,492 belong to restricted passages that never enter Neon (stored: 15,410). The
  summary now counts stored rows.
- **Server instructions** now cover the three tools above, search ranking semantics, and how to read
  a long document.
- **Test hygiene** — the `/gaps` page test depended on a header left by an earlier test and 401'd in
  isolation; it now authenticates explicitly.
- **Data (closed 2026-11-23, release 2026.11.23.4):** the NETL *Monitoring, Verification and
  Accounting* 2017 manual was in the corpus twice — and so were **11 other documents**. A corpus-wide
  scan found 12 documents under duplicate source URLs (1,702 duplicate open-licence chunks), and live
